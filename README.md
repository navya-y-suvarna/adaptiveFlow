Smart Traffic Signal for a Four-Way Intersection System

Overview
This project implements a smart traffic signal system for a four-way intersection. The system dynamically adjusts signal timing based on real-time vehicle density and gives priority to emergency vehicles using rule-based logic.

Problem
Traditional traffic signals use fixed timers, leading to congestion, long waiting times, and delays for emergency vehicles.

Solution
•	Adaptive signal control based on lane vehicle count  
•	Automatic emergency vehicle priority (green corridor)  
•	Fair and conflict-free signal switching  

 Results
•	Reduced average waiting time  
•	Faster emergency clearance  
•	Improved traffic flow compared to fixed-timer signals
